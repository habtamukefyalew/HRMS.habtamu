# HRMS (Human Resource Management System)

ይህ የሰው ኃይል አስተዳደር ሥርዓት (HRMS) ድርጅቶች የሰራተኞቻቸውን መረጃ፣ ቅጥር፣ የደመወዝ ክፍያ እና የስራ አፈጻጸም በአንድ ማዕከል በብቃት እና በዘመናዊ መልኩ እንዲያስተዳድሩ የተነደፈ የሶፍትዌር መፍትሄ ነው።

## 🚀 ዋና ዋና ክፍሎች (Features)

*   **የተጠቃሚዎች ምዝገባ እና ደህንነት (User Registration & Auth):** ለተጠቃሚዎች እና ለአስተዳዳሪዎች ሚናን መሰረት ያደረገ (Role-based) አስተማማኝ የምዝገባ እና የደህንነት ስርዓት።
*   **የሰራተኞች መገለጫ ማዕከል (Employee Profile Management):** የሰራተኞችን ሙሉ የግል መረጃ፣ የስራ መደብ፣ እና ታሪክ በጥራት መመዝገቢያ።
*   **የክትትል እና የፍቃድ አስተዳደር (Attendance & Leave Management):** የሰራተኞችን የስራ ሰዓት መከታተያ እና የፍቃድ (Leave) መጠየቂያና ማጽደቂያ ስርዓት።
*   **የደመወዝ እና ጥቅማጥቅም አስተዳደር (Payroll System):** ወርሃዊ የደመወዝ ስሌት፣ ታክስ እና ጥቅማጥቅሞችን በራስ-ሰር የሚያሰላ ክፍል።

## 🛠 የተጠቀሙባቸው ቴክኖሎጂዎች (Tech Stack)

*(ማሳሰቢያ፡ እንደ ፕሮጀክትዎ ሁኔታ ቴክኖሎጂዎቹን ይቀይሩ)*
*   **Backend:** Node.js / Python (Django/FastAPI) / C# (.NET)
*   **Frontend:** React.js / Vue.js / HTML & Tailwind CSS
*   **Database:** PostgreSQL / MySQL / MongoDB
